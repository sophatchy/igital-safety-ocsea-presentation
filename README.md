# សុវត្ថិភាពឌីជីថល និង OCSEA — កម្ពុជា (Digital Safety & OCSEA Presentation)

បទបង្ហាញជាភាសាខ្មែរ (Khmer-first) ស្តីអំពី **សុវត្ថិភាពឌីជីថល** និង **ការទប់ស្កាត់ការកេងប្រវ័ញ្ច និងការរំលោភបំពានផ្លូវភេទលើកុមារតាមប្រព័ន្ធអនឡាញ (OCSEA)** នៅប្រទេសកម្ពុជា។

---

## 🎯 គោលបំណងនៃបទបង្ហាញ (Objectives)

1. **យល់ដឹងអំពី OCSEA:** ពន្យល់និយមន័យ OCSEA (Online Child Sexual Exploitation and Abuse) ជាភាសាសាមញ្ញ និងបែងចែកឱ្យដាច់ពីបញ្ហាសន្តិសុខឌីជីថលទូទៅ។
2. **ស្គាល់ប្រភេទ និងសញ្ញាព្រមាន (6 Types & Warning Signs):**
   - ការបោកបញ្ឆោតកុមារតាមអនឡាញ (Online Grooming)
   - សម្ភារៈរំលោភបំពានផ្លូវភេទលើកុមារ (CSAM)
   - ការផ្សាយផ្ទាល់ការរំលោភបំពាន (Live-streaming of Abuse)
   - ការគំរាមកំហែងផ្លូវភេទ (Sextortion)
   - ការកេងប្រវ័ញ្ចដោយប្រាក់ អំណោយ ឬផលប្រយោជន៍ (Financial/Material Exploitation)
   - រូបភាពក្លែងក្លាយដោយបញ្ញាសិប្បនិម្មិត (AI Deepfakes)
3. **ទិន្នន័យ និងករណីជាក់ស្តែងនៅកម្ពុជា (Cambodia Context & Real Cases):**
   - ការសិក្សា Disrupting Harm Cambodia (2022) — UNICEF, ECPAT, INTERPOL
   - ករណីបណ្តាញ Telegram ចែកចាយ CSAM ជាង ៦,០០០ ឯកសារ ដែលត្រូវបានបង្ក្រាបដោយមានការចូលរួមពី APLE Cambodia (Fresh News ២០២៤)
   - ហានិភ័យការជួញដូរមនុស្ស និងការកេងប្រវ័ញ្ចពាក់ព័ន្ធ Scam Compounds (របាយការណ៍ Amnesty International ២០២៥–២០២៦)
   - ការពិត និងការយល់ច្រឡំអំពី Dark Web ឆ្លងដែន
   - បញ្ហាប្រឈមក្នុងការរកឃើញ និងរាយការណ៍ (ភាពអាម៉ាស់ ការបន្ទោសជនរងគ្រោះ កង្វះការយល់ដឹង)
4. **វិធានការការពារ និងឆ្លើយតប (4 Steps):** បញ្ឈប់ (Stop) · រក្សាទុកភស្តុតាង (Record) · រាយការណ៍ (Report) · គាំទ្រ (Support)។
5. **ធនធាន និងសេវាជំនួយនៅកម្ពុជា:**
   - **នាយកដ្ឋាននគរបាលប្រឆាំងការជួញដូរមនុស្ស និងការពារអនីតិជន (AHTJPD):** Hotline `1288` / `012 852 241`
   - **មជ្ឈមណ្ឌលតស៊ូមតិសម្រាប់កុមារ (Child Advocacy Center - CAC) / A21:** Hotline `010 22 07 71` / `071 72 10 771`
   - **APLE Cambodia:** Hotline `092 311 511` | [aplecambodia.org](https://www.aplecambodia.org/)
   - **Child Helpline Cambodia:** Hotline `1280` (ឥតគិតថ្លៃ) | [childhelplinecambodia.org](https://childhelplinecambodia.org/)
   - **Sophat.Space Help:** [sophat.space/help](https://sophat.space/help)

## 🖥️ របៀបប្រើប្រាស់បទបង្ហាញ (How to Run & Present)

បទបង្ហាញនេះត្រូវបានរចនាឡើងជាទម្រង់ **Single-Page HTML Web Presentation** ដែលមិនត្រូវការដំឡើង dependency ឬ server អ្វីទាំងអស់។

### បើកមើលក្នុងកុំព្យូទ័រ (Local Preview)
គ្រាន់តែបើកឯកសារ `index.html` ជាមួយ Browser ណាមួយ (Chrome, Safari, Firefox, Edge):
```bash
open index.html
```

### គ្រាប់ចុចបញ្ជា (Keyboard Shortcuts)
| គ្រាប់ចុច (Key) | សកម្មភាព (Action) |
|---|---|
| `→` / `Space` / `PageDown` | ទៅស្លាយបន្ទាប់ (Next slide) |
| `←` / `PageUp` | ត្រឡប់ទៅស្លាយមុន (Previous slide) |
| `Home` / `End` | ទៅស្លាយដំបូង / ស្លាយចុងក្រោយ |
| `P` | ទាញយកស្លាយជា PDF (Download PDF with high-quality Khmer rendering) |
| `B` | បើក/បិទ Big Screen Mode (ពង្រីកអក្សរខ្មែរធំច្បាស់សម្រាប់បញ្ចាំង Projector/TV) |
| `N` | បើក/បិទ Speaker Notes |
| `F` | បើក/បិទ Fullscreen Mode |
| `Touch Swipe` | អូសឆ្វេង/ស្ដាំលើអេក្រង់ទូរស័ព្ទ ឬ Tablet |

### មុខងារបន្ថែម (Features)
- 📥 **ទាញយក PDF (Download PDF):** ចុចប៊ូតុង **"ទាញយក PDF"** ឬចុចគ្រាប់ចុច `P` ដើម្បីទាញយកស្លាយទាំងអស់ជាឯកសារ PDF A4 Landscape ដែលបានរៀបចំយ៉ាងស្អាត៖
  - អក្សរខ្មែរ (`Kantumruy Pro`) មិនបែកស្រៈ ឬជើងអក្សរឡើយ ដោយសារប្រព័ន្ធរង់ចាំ WebFont Render ពេញលេញមុនពេល Save
  - រក្សារាងស្លាយ Landscape 16:9 ស្លាយមួយទំព័រមួយ មិនកាត់ផ្ដាច់កាត ឬខ្លឹមសារ
  - កំណត់ឈ្មោះឯកសារជា `សុវត្ថិភាពឌីជីថល-និង-OCSEA-ជី-សុផាត-Sophat-CHY.pdf` ដោយស្វ័យប្រវត្តិ
- 🔍 **Big Screen Mode (អក្សរធំច្បាស់):** ជួយពង្រីកទំហំអក្សរខ្មែរ និងគម្លាតបន្ទាត់ (line-height) ឱ្យកាន់តែធំច្បាស់ ងាយស្រួលមើលពីចម្ងាយលើអេក្រង់ធំ ទូរទស្សន៍ ឬម៉ាស៊ីនបញ្ចាំងស្លាយ (Projector) ដោយគ្រាន់តែចុចប៊ូតុង **"🔍 Big Screen"** ឬចុចគ្រាប់ចុច `B`។
- ☼ / ☾ **Day/Night Theme:** ប្ដូរពណ៌ផ្ទៃងាយស្រួលមើលតាមពន្លឺបន្ទប់ (Day/Night mode)។
- 📝 **Speaker Notes:** កំណត់ត្រាសម្រាប់អ្នកធ្វើបទបង្ហាញ ភ្ជាប់ទៅតាមស្លាយនីមួយៗ (ចុច `N`)។
