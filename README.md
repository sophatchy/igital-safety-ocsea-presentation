# សុវត្ថិភាពឌីជីថល និង OCSEA — កម្ពុជា (Digital Safety & OCSEA Presentation)
### Hosted by A21 Cambodia (Child Advocacy Center) · Presented by Sophat CHY

បទបង្ហាញកម្រិតខ្ពស់ពីរភាសា (Bilingual: **ភាសាខ្មែរ 🇰🇭 សម្រាប់ពេលព្រឹក** និង **English 🇬🇧 សម្រាប់ពេលរសៀល**) ស្តីអំពី **សុវត្ថិភាពឌីជីថល** និង **ការទប់ស្កាត់ការកេងប្រវ័ញ្ច និងការរំលោភបំពានផ្លូវភេទលើកុមារតាមប្រព័ន្ធអនឡាញ (Online Child Sexual Exploitation and Abuse - OCSEA)** នៅប្រទេសកម្ពុជា។

---

## 🎯 គោលបំណងនៃបទបង្ហាញ (Presentation Objectives)

1. **យល់ដឹងអំពី OCSEA (Understand OCSEA):** ពន្យល់និយមន័យ OCSEA (Online Child Sexual Exploitation and Abuse) និងបែងចែកឱ្យដាច់ស្រឡះពីបទល្មើស Cybercrime ធម្មតា។
2. **ស្គាល់ ៦ ប្រភេទ និងសញ្ញាព្រមាន (6 Types & Warning Signs):**
   - ការបោកបញ្ឆោតកុមារតាមអនឡាញ (Online Grooming)
   - សម្ភារៈរំលោភបំពានផ្លូវភេទលើកុមារ (CSAM)
   - ការផ្សាយផ្ទាល់ការរំលោភបំពាន (Live-streaming of Abuse)
   - ការគំរាមកំហែងផ្លូវភេទ (Sextortion)
   - ការកេងប្រវ័ញ្ចដោយប្រាក់ ឬអំណោយ (Financial/Material Exploitation)
   - រូបភាពក្លែងក្លាយដោយបញ្ញាសិប្បនិម្មិត (AI Deepfakes)
3. **ទិន្នន័យ និងករណីជាក់ស្តែងនៅកម្ពុជា (Cambodia Context & Real Cases):**
   - ករណីបណ្តាញ Telegram ចែកចាយ CSAM ជាង ១៩,០០០ ឯកសារ ដែលបង្ក្រាបដោយមានការចូលរួមពី APLE (Fresh News ២០២៤)
   - ហានិភ័យការជួញដូរមនុស្ស និង Scam Compounds (របាយការណ៍ Amnesty International ២០២៥–២០២៦)
   - ការពិតអំពី Dark Web និងការទប់ស្កាត់លើ App ប្រចាំថ្ងៃ (Facebook, Telegram, TikTok, Games)
   - បញ្ហាប្រឈមក្នុងការរកឃើញ (ភាពអាម៉ាស់ ការបន្ទោសជនរងគ្រោះ)
4. **រូបមន្ត ៤ ជំហានឆ្លើយតប (4-Step Action Framework):** បញ្ឈប់ (Stop) · រក្សាទុកភស្តុតាង (Record) · រាយការណ៍ (Report) · គាំទ្រ (Support)។
5. **បណ្តាញសេវាជំនួយ និងលេខទូរស័ព្ទបន្ទាន់នៅកម្ពុជា (Cambodia Support Hotlines - [sophat.space/help](https://sophat.space/help)):**
   - **នាយកដ្ឋាននគរបាលប្រឆាំងការជួញដូរមនុស្ស និងការពារអនីតិជន (AHTJPD):** Hotline `1288` / `012 852 241`
   - **មជ្ឈមណ្ឌលតស៊ូមតិសម្រាប់កុមារ (Child Advocacy Center - CAC) / A21:** Hotline `010 22 07 71` / `071 72 10 771`
   - **នាយកដ្ឋានប្រឆាំងបទល្មើសបច្ចេកវិទ្យា (Anti-Cybercrime Police):** [hotline.police.gov.kh](https://hotline.police.gov.kh) / App Kapea Scams
   - **CamCERT (ក្រុមការងារឆ្លើយតបបន្ទាន់បញ្ហាសន្តិសុខបច្ចេកវិទ្យា MPTC):** Phone `+855 23 722 391`
   - **APLE Cambodia:** Hotline `092 311 511` | [aplecambodia.org](https://www.aplecambodia.org/)
   - **Child Helpline Cambodia:** Hotline `1280` (ឥតគិតថ្លៃ ២៤/៧) | [childhelplinecambodia.org](https://childhelplinecambodia.org/)
   - **CWCC (មជ្ឈមណ្ឌលការពារសិទ្ធិកុមារ និងស្ត្រី):** Hotline `012 828 732` / `023 993 429` | [cwcc.org.kh](https://cwcc.org.kh)
   - **Take It Down (NCMEC):** [takeitdown.ncmec.org](https://takeitdown.ncmec.org)
   - **Sophat.Space Help:** [sophat.space/help](https://sophat.space/help)

## 🖥️ មុខងារពិសេសនៃបទបង្ហាញ (Key Deck Features)

1. **🌐 Bilingual Engine (Khmer 🇰🇭 <-> English 🇬🇧):**
   - ប្ដូរភាសាភ្លាមៗដោយចុចប៊ូតុង **"🇬🇧 English"** ឬចុចគ្រាប់ចុច `L`។
   - គាំទ្រទាំងស្រុងសម្រាប់ **សិក្ខាសាលាពេលព្រឹកជាភាសាខ្មែរ** និង **សិក្ខាសាលាពេលរសៀលជាភាសាអង់គ្លេស** (រួមទាំង Speaker Notes ជាភាសាអង់គ្លេសពេញលេញ)។
2. **🚫 Non-Scrolling Slide Viewport (គ្មានការ Scroll ស្លាយ):**
   - ស្លាយទាំង ២០ ត្រូវបានរចនាឡើងយ៉ាងម៉ត់ចត់ដើម្បី **Fit ពេញអេក្រង់ ១០០% ដោយគ្មាន Scrollbar** លើគ្រប់ទំហំអេក្រង់ (Projector 1024x768, Laptop 1366x768, Monitor 1080p, TV 4K)។
3. **✨ A21-Inspired Brand Design:**
   - រចនាឡើងតាមអត្តសញ្ញាណអង្គការ A21 Cambodia (Child Advocacy Center) ជាមួយពណ៌ signature amber/gold (`#f59e0b`), deep carbon navy (`#090d16`), និង crisp typography។
4. **📄 A4 High-Resolution PDF Download:**
   - ចុចប៊ូតុង **"📥 ទាញយក A4 PDF"** ឬចុចគ្រាប់ចុច `P`។
   - មានផ្ទាំងណែនាំ Setting ងាយស្រួល (Landscape · A4 · Save as PDF)។
   - ធានារក្សាអក្សរខ្មែរ `Kantumruy Pro` មិនបែកស្រៈ ឬជើងអក្សរឡើយ ហើយស្លាយមួយទំព័រមួយយ៉ាងស្អាត។

## ⌨️ គ្រាប់ចុចបញ្ជា (Keyboard Shortcuts)

| គ្រាប់ចុច (Key) | សកម្មភាព (Action) |
|---|---|
| `→` / `Space` / `PageDown` | ទៅស្លាយបន្ទាប់ (Next slide) |
| `←` / `PageUp` | ត្រឡប់ទៅស្លាយមុន (Previous slide) |
| `Home` / `End` | ទៅស្លាយដំបូង / ស្លាយចុងក្រោយ |
| `L` | **ប្ដូរភាសា (Toggle Khmer / English)** |
| `P` | **ទាញយកស្លាយជា A4 PDF (Print / Save A4 PDF)** |
| `B` | បើក/បិទ Big Screen Mode (ពង្រីកអក្សរធំច្បាស់សម្រាប់បញ្ចាំង Projector/TV) |
| `N` | បើក/បិទ Speaker Notes (កំណត់ត្រាអ្នកធ្វើបទបង្ហាញ) |
| `F` | បើក/បិទ Fullscreen Mode (ពេញអេក្រង់) |
| `Touch Swipe` | អូសឆ្វេង/ស្ដាំលើអេក្រង់ទូរស័ព្ទ ឬ Tablet |
